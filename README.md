# YouTube-analogue
YouTube Clone — учебный проект, созданный с использованием HTML и CSS. В проекте реализован интерфейс видеохостинга с главной страницей, навигационной панелью, поисковой строкой, категориями и карточками видеороликов.

Клон интерфейса YouTube с навигацией, поиском, категориями и сеткой видеокарточек. Проект создан для практики современной веб-вёрстки и работы с CSS.
